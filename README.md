# 🚜 Escavadora 3D em VRML

Projeto de modelagem tridimensional de uma escavadeira desenvolvido utilizando **VRML (Virtual Reality Modeling Language)** para a disciplina de **Introdução à Computação Gráfica**.

## 📌 Sobre o Projeto

O projeto consiste na construção de um modelo tridimensional de uma escavadeira utilizando VRML, explorando conceitos fundamentais de computação gráfica por meio da composição de formas geométricas, transformações espaciais e organização de objetos em um ambiente 3D.

O desenvolvimento teve como objetivo aplicar os conhecimentos adquiridos durante a disciplina na criação de um objeto tridimensional, trabalhando com posicionamento, escala e composição de elementos para representar a estrutura de uma escavadeira.

## 🛠️ Tecnologias Utilizadas

- **VRML** — Linguagem utilizada para descrição e construção de ambientes e objetos tridimensionais.
- **Computação Gráfica 3D** — Aplicação de conceitos de modelagem e composição de objetos geométricos.

## 📚 Conceitos Aplicados

- Modelagem tridimensional;
- Composição de formas geométricas;
- Transformações geométricas;
- Posicionamento e escala de objetos em um ambiente 3D;
- Organização de elementos tridimensionais.

## 🎯 Objetivo

Aplicar os conceitos de Introdução à Computação Gráfica na criação de um modelo tridimensional, desenvolvendo conhecimentos sobre representação espacial, construção geométrica e estruturação de objetos utilizando VRML.
